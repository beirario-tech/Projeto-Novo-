# PalletFlow Pro — Sistema de Controle de Paletes e Expedição

Aplicação desenvolvida para controle de volumes e expedição de paletes para transferência entre lojas.

## 🌐 Acesso Online (GitHub Pages)

A aplicação está publicada e pronta para uso em:
👉 **[https://matheusvictorfernandesromeu4-tech.github.io/Projeto-Novo-/](https://matheusvictorfernandesromeu4-tech.github.io/Projeto-Novo-/)**

## 🚀 Execução Local

1. Abra o terminal no diretório do projeto e execute:
```bash
npm start
```
2. Acesse no navegador:
```
http://localhost:3000
```

## 📋 Recursos Principais

- **Seleção de Loja:** Escolha entre lojas cadastradas ou cadastre novas na hora.
- **Controle de Quantidade de Paletes:** Gera etiquetas sequenciais automáticas (`01/05`, `02/05`, etc.).
- **Placa do Veículo:** Formatação automática com suporte Mercosul e Padrão.
- **Conferente & Data:** Registro do responsável e data da expedição.
- **Impressão Pronta para Colar:** 
  - Térmica (100x150mm) padrão Zebra / Argox / Elgin.
  - Sulfite A4 para impressoras comuns.
  - Romaneio de Carga / Manifesto com checklist de volumes.
- **Códigos de Barras e QR Code 100% Offline:** Sem dependências externas de internet no galpão.
- **Histórico & Rastreabilidade:** Registro completo de todas as transferências com busca e reimpressão em 1 clique.
